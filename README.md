#### 🏠 RealEstateManager [Version Java / XML] – Application de Gestion Immobilière
*Application métier complète destinée aux agents immobiliers pour la gestion et le suivi des biens.*
* **Ce que j'ai mis en pratique :** Persistance locale intégrale avec Room DB, architecture MVVM en Java, et interfaces utilisateur dynamiques en XML.
* **Fonctionnalités & APIs :** Intégration de Google Maps SDK pour l'affichage dynamique des biens aux alentours et génération d'une Static Map personnalisée sur la fiche détaillée de chaque logement.

#### 🔄 RealEstateManager [Version Kotlin] – Migration, Refactoring & Modernisation
*Refactoring architectural et technologique complet de l'application précédente pour s'aligner sur les derniers standards de Google.*
* **Ce que j'ai mis en pratique :** Migration à 100% de la base de code Java vers Kotlin. Remplacement total des layouts XML par des interfaces déclaratives en Jetpack Compose.
* **Focus Qualité & IA :** Gestion asynchrone moderne via les Coroutines et Kotlin Flows. Utilisation de l'IA comme copilote pour optimiser le processus de refactoring des classes de données et la mise en place de l'injection de dépendances.
* 👉 [Voir le dépôt Kotlin](https://github.com[NOM_DU_REPO_REALESTATE_KOTLIN])

#### 🍕 Go4Lunch – Application Collaborative de Planification de Repas [Java]
*Une application sociale permettant à des collègues de travail de choisir leur restaurant pour le déjeuner.*
* **Ce que j'ai mis en pratique :** Authentification sécurisée (OAuth2 via Firebase Auth pour Google et GitHub), gestion de base de données en temps réel avec Firebase Cloud Firestore.
* **Cartographie :** Intégration et manipulation de cartes interactives basées sur OpenStreetMap.
* **Le petit + :** Logique collaborative permettant à un utilisateur de déclarer son intention de repas, rendant l'information visible instantanément par toute son équipe.
* 👉 [Voir le dépôt Go4Lunch](https://github.com/Lafadel19/Go4Lunch)
